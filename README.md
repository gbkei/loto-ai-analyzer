# ロト AI アナライザー v1.1

iPhone Safari向けのロト6・ロト7購入候補管理Webアプリ（PWA）。**非公式**で、宝くじの購入・決済は行いません。

## 機能
- ロト6（1〜43から6個、200円）とロト7（1〜37から7個、300円）を切替
- 次回抽選回ごとに5口を生成・保存。手動で再生成可能
- 公平なランダム生成と過去100回の出現頻度を参考にした生成（優位性なし）
- CSV取込（UTF-8、Shift_JIS）と直近30/100回・全期間の分析
- 数字のコピー、CSVダウンロード、手動での当選本数字との一致数照合
- ローカル保存、JSONバックアップ・復元
- PWAとしてホーム画面追加（HTTPS公開時）

## iPhoneで使うには
1. このフォルダ一式を静的Webホスティング（GitHub Pages、Cloudflare Pagesなど）に**HTTPS**で公開します。単独のHTMLをiPhoneの「ファイル」で開くだけでは保存・PWA機能が正しく動かない場合があります。
2. iPhoneのSafariで公開URLを開き、「共有」→「ホーム画面に追加」を選びます。
3. ロト6・ロト7を切り替え、抽選回を指定して「5口を作成・保存」を押します。
4. 当選結果CSVを読み込むと分析できます。公式サイトで数字を確認して手動購入してください。

## CSVフォーマット例
```
回号,抽選日,本数字1,本数字2,本数字3,本数字4,本数字5,本数字6
1000,2025/01/01,1,7,13,22,35,41
```
ロト7は「本数字7」を追加。上記の数字は**形式例であり、実際の当選結果ではありません**。ボーナス数字は読み込まず、本数字だけ集計します。CSVヘッダーがない場合は「回号,抽選日,本数字...」の順とします。回号と日付は実際の抽選情報を使ってください。

## 重要な制限
- 最新の当選結果は楽天×宝くじ、過去の履歴はthekyoの非公式CSVから取得します。公式購入画面への数字の自動入力、購入履歴の取得は未実装です。
- iOS Safari拡張機能は含みません。公式サイトの規約・DOM構造・配布要件の検証が必要です。
- 抽選回の自動判定はCSVの最新回＋1に基づく暫定値です。必ず公式サイトで確認してください。
- 生成候補は予測ではありません。公平な抽選ではどの組み合わせも当選確率は同じです。
- データはブラウザのlocalStorageに保存されます。ブラウザデータ削除・端末変更で消えるためJSONバックアップを保管してください。
- 端末内のバックアップやCSVは個人情報を含めず管理してください。

## 配置ファイル
- `index.html`: アプリ本体（外部JavaScript不要）
- `manifest.webmanifest`: ホーム画面追加設定
- `sw.js`: オフライン用キャッシュ
- `icon.svg`: アイコン

## 公開データの更新と取得ボタン
- GitHub PagesのSourceはGitHub Actionsを使用します。
- 最新結果は楽天×宝くじのロト6・ロト7当せん番号案内から取得します。
- 過去履歴はthekyoの公開CSV（非公式）で補います。両方にある回号は日付と本数字が一致することを確認します。
- 回号の欠落、数字の重複・範囲違反、取得元同士の不一致、最新回の後退では更新を止めます。どちらかのゲームが失敗すると既存JSONを保持します。
- GitHub Actionsが月・木・金の日本時間22:20ごろに更新を試み、成功後にPagesへ反映します。定刻実行・将来の取得成功は保証されません。
- 「最新データ取得」は更新済みの公開JSONを端末へ読み込むボタンです。押すたびに上流サイトを取得するものではありません。アプリ起動時にも同じデータを読み込みます。
- 出典と公開データ更新時刻をアプリ内に表示します。サイトの更新遅延により最新抽選が未掲載の場合があります。当選の最終確認は公式発表を使用してください。
- 購入確定・決済の自動化は行いません。
